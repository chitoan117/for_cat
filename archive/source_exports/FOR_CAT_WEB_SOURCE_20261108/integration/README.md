# Source tham khảo tích hợp ESP32

Thư mục esp32 là bản firmware hiện tại sau sửa phản hồi mèo ngày08/11: nhận AI và E1<=30cm, hai mẫu mới được theo dõi trước; có dự phòng mất heartbeat Jetson theoE1<=20cm+PIR. Cần cả esp32.ino,CatNearGate.h vàFallbackGate.h khi biên dịch.

Đây là tài liệu tham khảo cho giao tiếp phần web/bridge với bộ điều khiển, không cần nạp để chạy frontend mô phỏng. Không tự động nạp hoặc cấp thức ăn từ gói source này. Mốc cân lưuNVS không được xuất kèm. Phần nguồn độc lập và thực nghiệm cúp điện chưa hoàn tất tại thời điểm bàn giao.
