# First pilot collection plan

Goal: verify camera angle, label clarity, bounded capture/import/replay, train/evaluation plumbing and failure cases—not final accuracy.

Observe normal voluntary activity of OWNER_CAT: approach food/water, natural eating/drinking, leaving and other movement. Collect OTHER_OBJECT negatives (empty scene, bowl, ordinary handling with privacy review). OTHER_CAT only if naturally available and safe; if absent, record the coverage gap. Never provoke conflict, restrict water, stress an animal or manufacture dangerous behavior.

Use separate explicit session IDs and record source, UTC collection start, lighting/viewpoint/occlusion, food type and disturbances. Try available natural lighting/view angles without destabilizing the rig. Select temporally spaced frames; inspect dHash warnings instead of retaining thousands of near-identical images. Label uncertain frames honestly. Hold out complete source/session groups.

Deliverables: real session manifests/transcripts, reviewed samples, disagreements/failure examples, pilot release report, class counts/usable rate and proposed next collection improvements. A later small real training trial is permitted only with actual data and a recorded experiment config; held-out accuracy is not a pilot goal. No pilot collection or training has occurred in this pass.
