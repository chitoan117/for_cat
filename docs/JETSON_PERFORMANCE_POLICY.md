# Jetson performance/backpressure policy — HOST TEST VERIFIED, NOT JETSON VERIFIED

Configuration defaults are bounded preparation choices, **not measured optimal Nano settings**: capture 640×480 at requested 10 FPS, inference budget 2 FPS, processing maximum 640×480, FRAME_SKIP=1, queue depth exactly 1, max frame age 1 second. Capture resolution/FPS are best-effort negotiated by the backend; `benchmark_camera` reports actual readings later. Real identity/behavior/detector confidence thresholds default **unconfigured** pending evaluation.

The observation path reads one frame, skips stale/over-budget frames, resizes processing input and runs synchronous prediction; there is **no producer frame queue**. Slow inference delays acquisition rather than accumulating Python images. Driver buffer size 1 is requested where supported; recommended trusted GStreamer input ends in `appsink max-buffers=1 drop=true sync=false`. Actual kernel/decoder buffering and V4L2 staleness remain hardware tests, not a guarantee from this configuration.

One explicitly started managed `ObservationService` thread may run beside REST; default app import/lifespan starts none. It has bounded frame/time/failure counts, interruptible pacing, backoff capped at 2 s and one pending completed session write. No normal per-frame DB/log writes. Latency statistics retain at most 256 samples. Canonical history/ledger/buffers are independently capped. A driver/model stuck in a native call cannot always be interrupted by Python: manual probes use a killable child process, service stop reports FAULTED if join times out, and systemd provides process-level termination. Real blocking-driver shutdown requires testing.

`tools.benchmark_pipeline --frames 300` reports HOST BENCHMARK ONLY with synthetic 16×16 assets/models. It measures software overhead, not real cat inference, GPU acceleration, Nano performance or webcam FPS. P95 uses the last bounded 256-frame window; mean uses scalar accumulated latency. `--video` is explicit local-file replay and fake model timing only. No camera is opened by pipeline benchmarks.
